# เบื้องหลังพิพิธภัณฑ์เด็ก (Behind the Children's Museum)

เกมสั้นบนมือถือ (~5 นาที) ให้ผู้เล่นลองเป็นเจ้าหน้าที่พิพิธภัณฑ์เด็กหนึ่งวัน ตั้งแต่ก่อนเปิดจนหลังปิด

เล่นได้ที่: https://chokun3344-tech.github.io/behind-childrens-museum/

ภาพถ่ายจริงจาก ศูนย์การเรียนรู้สำหรับครอบครัว (Bangkok Family Center) · พี่หญิงเป็นบุคคลจริง ใช้ภาพและคำพูดโดยได้รับอนุญาต
